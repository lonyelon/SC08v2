#+title: SC08v2 default instruction set

The SC08v2 has quite a weird set of instructions by default.
First, we have the [[instructions]] themselves, which tell the CPU what to do.
[[Instruction modifiers]] tell it from where to get the data (or where to store it) after the instruction executed.

For example, ~ADD.num 0x60~ is the function ~ADD~ followed by the modifier ~num~.
It means "add to whatever is on the LDA registry the number =0x60=".

* Intrucctions

The table below explains what every instruction in the CPU does.
Every byte value not in the list is assumed to do nothing, the same as ~NOI.noa~.

|-------+--------------+-------------------------------------------------|
| Name  | Byte         | Value                                           |
|-------+--------------+-------------------------------------------------|
| =NOI= | =00 000 mmm= |                                                 |
| =NAN= | =00 001 mmm= | Bitwise NAND operation between =DTA= and =DTB=. |
| =ADD= | =00 010 mmm= | Add =DTA= and =DTB=.                            |
| =SUB= | =00 011 mmm= | Substract =DTB= from =DTA=.                     |
| =SHL= | =00 100 mmm= | Shift =DTA= left.                               |
| =SHR= | =00 101 mmm= | Shift =DTA= right.                              |
| =EQU= | =00 110 mmm= | Check if =DTA= = =DTB=.                         |
| =GRE= | =00 111 mmm= | Check if =DTA= > =DTB=.                         |
| =LDD= | =01 000 mmm= | Load data into the =DTA= registry.              |
| =STD= | =10 000 mmm= | Store data from the =DTA= registry.             |
| =JUM= | =11 000 mmm= | Conditional jumps. Only jumps if ~DTA != 0xFF~. |
|-------+--------------+-------------------------------------------------|

As we can see, every instruction has two bits for the ID, three for the ALU operation (has to be =000= in non-ALU instructions to allow reading from =DTA=), and three for the modifier.

* Instruction modifiers

|--------------------+--------+---------------------------------------------------------------------------|
| Name [extra bytes] | m-bits | Description                                                               |
|--------------------+--------+---------------------------------------------------------------------------|
| =noa=              |    000 | Do nothing/Pass the value of =DTA=. On ~LDD~ it loads the value of =IFL=. |
| =num #1 [#2]=      |    001 | Hardcoded byte (could be 2 bytes for ROM operations like ~JUM~).          |
| =ram #1=           |    010 | RAM at =#1=.                                                              |
| =rom #1 #2=        |    011 | ROM at =#1 #2=.                                                           |
| =prr=              |    100 | RAM at =RAM[DTA]= (pointer)                                               |
| =ptr #1=           |    101 | RAM at =RAM[#1]= (pointer)                                                |
| =aux=              |    110 | Manage the =AUX= registry.                                                |
| =ios=              |    111 | I/O registries.                                                           |
|--------------------+--------+---------------------------------------------------------------------------|

* Valid instruction-modifier combinations

|-----------------+--------------------------------------------------------------------------------|
| Instruction     | Action                                                                         |
|-----------------+--------------------------------------------------------------------------------|
| ~ALU.noa~       | DTA = DTA                                                                      |
| ~ALU.num #1~    | DTA = DTA <> #1                                                                |
| ~ALU.ram #1~    | DTA = DTA <> RAM[#1]                                                           |
| ~ALU.rom #1 #2~ | DTA = DTA <> ROM[#1][#2]                                                       |
| ~ALU.prr~       | DTA = DTA <> RAM[DTA]                                                          |
| ~ALU.ptr #1~    | DTA = DTA <> RAM[#1]                                                           |
| ~ALU.ios~       | DTA = DTA <> INP                                                               |
|-----------------+--------------------------------------------------------------------------------|
| ~LDD.noa~       | DTA = IFL                                                                      |
| ~LDD.num #1~    | DTA = #1                                                                       |
| ~LDD.ram #1~    | DTA = RAM[#1]                                                                  |
| ~LDD.rom #1 #2~ | DTA = ROM[#1][#2]                                                              |
| ~LDD.prr~       | DTA = RAM[DTA]                                                                 |
| ~LDD.ptr #1~    | DTA = RAM[#1]                                                                  |
| ~LDD.ios~       | DTA = INP                                                                      |
|-----------------+--------------------------------------------------------------------------------|
| ~STD.noa~       | Also called NOI.noa. Do nothing.                                               |
| ~STD.num~       | NOI.noa.                                                                       |
| ~STD.ram #1~    | RAM[#1] = DTA                                                                  |
| ~STD.rom #1 #2~ | ROM[#1][#2] = DTA                                                              |
| ~STD.prr~       | RAM[DTA] = DTA                                                                 |
| ~STD.ptr #1~    | RAM[#1] = DTA                                                                  |
| ~STD.ios~       | OUT = DTA                                                                      |
|-----------------+--------------------------------------------------------------------------------|
| ~JUM.noa~       | Also called NOI.noa. Do nothing.                                               |
| ~JUM.noa~       | PC = #1 #2                                                                     |
| ~JUM.ram #1 #2~ | PC = RAM[#1] RAM[#2]                                                           |
| ~JUM.rom~       | NOI.noa? Only valid if ROM has 2 address bytes, PC S forces SWT and max(PC)=15 |
| ~JUM.prr #1~    | NOI.noa? PC = RAM[DTA] RAM[#1]                                                 |
| ~JUM.ptr #1 #2~ | NOI.noa? PC = RAM[#1] RAM[#2]                                                  |
| ~JUM.ios #1~    | NOI.noa? PC = INP #1                                                           |
|-----------------+--------------------------------------------------------------------------------|
